## Problem Statement

Security is increasingly embedded in horizontal enterprise platforms (cloud, workflow, payments, networking). How does this reshape startup strategy, acquirer maps, and the bar for standalone point solutions?

## Target Buyer / User

- Security startup founders planning exit paths and platform partnerships
- Practitioners evaluating build-vs-buy when platforms ship native security
- Investors modeling consolidation risk

## Why Now?

Record platform M&A: Google/Wiz ($32B), ServiceNow/Armis ($7.75B), Mastercard/Recorded Future ($2.65B), Cisco/Splunk ($28B)—documented in Venture in Security and corroborated by press ([Google blog](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/wiz-acquisition/)).

## Initial Hypothesis

Platform vendors acquire security to make core products stickier and AI-deployable; point solutions must be substantially better than "good enough" native features or become acquisition targets for non-traditional buyers.
